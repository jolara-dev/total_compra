# Cálculo del total de una compra
Estudiante: JHONNY MARCELO LARA MENDEZ 💻  

## Descripción
El programa calcula cuánto debe pagar un cliente por varias unidades de un mismo producto.

La función calcular_total recibe dos parámetros: precio y cantidad.
Multiplica estos valores y devuelve el total de la compra.

## Ejemplo
Si el precio del producto es $10 y se compran 3 unidades el total de la compra es $30.

## Ejecución
Ejecutar el archivo total_compra.py con Python.
El resultado se muestra en la consola.
